Web & UI/UX Design

Kaza Magazine Website

A digital experience designed to support Kaza Magazine’s online presence through clearer navigation, stronger content structure, and a more usable interface.

Role

UX / Web Designer

Interface structure, layout direction, usability thinking, and digital visual communication.

Scope

Website Experience

Web layouts, registration flow, content presentation, and publication-oriented navigation.

Focus

Usability & Content Flow

Improving how users discover content, interact with the platform, and move through the magazine experience online.

Project Overview

Transforming an editorial brand into a more structured digital experience.

Kaza Magazine needed a web experience that could translate the rhythm and visual appeal of an editorial publication into a more functional digital environment.

The project focused on organizing content, improving usability, supporting user registration, and creating a stronger interface for readers to engage with architecture, interiors, and lifestyle content online.

Design Direction

A cleaner interface for editorial discovery and digital interaction.

The layouts balance publication-style visual storytelling with practical interface needs, including hierarchy, registration, browsing behavior, and content organization.
